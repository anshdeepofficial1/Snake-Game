## ✨ Overview

Snake Game is a lightweight console game written in C that demonstrates the fundamentals of real-time input, game loops, collision detection, score tracking, random fruit placement, and dynamic snake movement.

## 🎮 Features

- Real-time keyboard controls
- Growing snake and score system
- Random fruit generation
- Self-collision detection
- Edge wrap-around movement
- Restart and exit controls
- Fast, dependency-free terminal gameplay

## ⌨️ Controls

| Key | Action |
| --- | --- |
| `W` | Move up |
| `A` | Move left |
| `S` | Move down |
| `D` | Move right |
| `R` | Restart |
| `X` | Exit |

## 🛠️ Tech

- **Language:** C
- **Input:** `conio.h`
- **Timing:** Windows `Sleep()`
- **Interface:** Console / terminal

## 🚀 Getting Started

```bash
git clone https://github.com/anshdeepofficial/Snake-Game.git
cd Snake-Game
```

Compile the C source with a Windows-compatible C compiler, then run the generated executable from a terminal.

## 🧠 What This Project Demonstrates

The project is a compact example of state management, coordinate-based rendering, user input handling, randomization, collision logic, and continuous game-loop programming in C.
